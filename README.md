# ShopFast Retail - Inventory Management API

## Contexto de la Organización
ShopFast Retail es una empresa de comercio electrónico en línea. El equipo de desarrollo ha construido una API ligera en Python (Flask) para gestionar el catálogo de productos y el stock de las tiendas. Antes de liberar la versión a producción, la dirección técnica ha solicitado una auditoría preliminar de seguridad debido a sospechas sobre malas prácticas de desarrollo y posibles vulnerabilidades en el repositorio.

## Objetivo de la Fase 1
Los alumnos deben realizar un análisis preliminar y un plan de auditoría **sin ejecutar herramientas de escaneo todavía**, revisando la estructura del código y los archivos de configuración para identificar los riesgos esperados.
